# Scroll-Driven Hero Section Animation

A modern, interactive hero section built with React, GSAP, ScrollTrigger, and Tailwind CSS.

The project demonstrates smooth entrance animations and a scroll-driven visual experience where the main visual element responds dynamically to the user's scroll position.

## ✨ Features

- Full-screen hero section
- Letter-spaced animated headline
- Staggered entrance animations
- Animated impact statistics
- Scroll-driven car animation
- Smooth GSAP ScrollTrigger interactions
- Responsive layout for different screen sizes
- Transform-based animations for better performance
- Modern dark and purple visual design
- Additional scroll-driven experience section

## 🛠️ Technologies Used

- **React**
- **JavaScript**
- **GSAP**
- **GSAP ScrollTrigger**
- **Tailwind CSS**
- **HTML5**
- **CSS3**
- **Vite**
